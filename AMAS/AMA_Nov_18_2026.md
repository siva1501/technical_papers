## 1. Anoop Vantagodi: How to extract a date whose value is in string format?

Use `datetime.strptime()` to convert a string into a date or datetime object.

```python
from datetime import datetime

d = datetime.strptime("18-11-2026", "%d-%m-%Y").date()
print(d)  # 2026-11-18
```

| --- | --- |
