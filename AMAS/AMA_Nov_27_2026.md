# AMAS Questions and Answers

## 1. What is `em` in CSS?

`em` is a relative CSS unit used to define font size, width, margin, and padding.
It is calculated based on the font size of the parent element.

Example: `font-size: 2em;`

## 2. Difference between `<title>` and `<h1>` tags

- `<title>` defines the title displayed in the browser tab.
- `<h1>` defines the main heading displayed on the webpage.
- `<title>` is written inside `<head>`, whereas `<h1>` is written inside `<body>`.

## 3. Difference between `min-width` and `max-width`

- `min-width` sets the minimum width an element can have.
- `max-width` sets the maximum width an element can have.
- Example: `min-width: 200px; max-width: 500px;`

## 4. Difference between `pop()` and `del` in Python

- `pop()` removes an element and returns the removed value.
- `del` removes an element or variable without returning its value.
- Example: `my_list.pop()` and `del my_list[0]`.

## 5. What is `NUMERIC` in SQL?

`NUMERIC` is a data type used to store exact numeric values.
It is useful for storing decimal numbers, especially financial values.

Example: `salary NUMERIC(10,2)`

## 6. How to add stylesheets in HTML?

There are three ways to add CSS to HTML:

1. **Inline CSS** – using the `style` attribute.
2. **Internal CSS** – using the `<style>` tag inside `<head>`.
3. **External CSS** – using the `<link>` tag to connect a CSS file.

## 7. List three font properties in CSS

1. `font-size` – Sets the size of the text.
2. `font-family` – Sets the font style.
3. `font-weight` – Sets the thickness of the text.

## 8. What will be the output when we use `pop()` in a set?

- `pop()` removes and returns an arbitrary element from a set.
- We cannot specify which element to remove.
- Example: `my_set = {10, 20, 30}` → `my_set.pop()` may return any one element.

## 9. Difference between `width` and `max-width`

- `width` sets the width of an element.
- `max-width` sets the maximum allowed width of an element.
- `max-width` is useful for creating responsive layouts.

## 10. What is the use of media queries in CSS?

Media queries are used to create responsive websites.
They help change styles based on screen size and device type.

Example: `@media (max-width: 768px) { ... }`

## 11. Difference between `sticky` and `fixed` in CSS

- `position: fixed` keeps an element in the same position on the screen even when scrolling.
- `position: sticky` behaves like a normal element until it reaches a specified scroll position.
- Sticky elements remain within their containing block, whereas fixed elements are generally positioned relative to the viewport.

## 12. Difference between `disabled` and `readonly` in HTML input

- `disabled` makes an input field unusable and prevents its value from being submitted with the form.
- `readonly` prevents users from editing the input but allows its value to be submitted.
- Both prevent users from changing the input value directly.

## 13. Difference between `append()` and `extend()` in Python

- `append()` adds one element to the end of a list.
- `extend()` adds multiple elements from an iterable to a list.
- Example: `my_list.append([4, 5])` adds a nested list, while `my_list.extend([4, 5])` adds individual elements.

## 14. Difference between shallow copy and deep copy

- Shallow copy creates a new object but shares references to nested objects.
- Deep copy creates a new object and also copies nested objects.
- Changes to nested objects in a shallow copy can affect the original, but deep copy avoids this.

## 15. What is the use of Stack and Queue data structures?

**Stack**

- Stack follows LIFO (Last In, First Out).
- The last inserted element is removed first.
- Example: Undo operation.

**Queue**

- Queue follows FIFO (First In, First Out).
- The first inserted element is removed first.
- Example: Printer queue.

## 16. What is cascading in CSS?

CSS cascading is the process of deciding which CSS rule applies when multiple rules target the same element.
It considers importance, specificity, and source order.
The rule with higher priority is applied.
