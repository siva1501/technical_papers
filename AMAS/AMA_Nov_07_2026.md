# Python, OOP, Git & Linux CLI – Questions and Answers – 6th November 2026

1. **Anoop Vantagodi:** What is Polymorphism?  
   **Answer:** Polymorphism means one method or function can behave differently depending on the object.

2. **Khushi Rani:** How to restore a committed file with unstaging?  
   **Answer:** Use `git reset HEAD~1` to undo the latest commit while keeping changes unstaged. Use `git restore --staged filename` to unstage a staged file.

3. **Kiran B L:** Command to append the text to a file?  
   **Answer:** Use `echo "your text" >> filename` to append text to a file.

4. **Kummari Amaresh:** Command to create a branch and switch to it?  
   **Answer:** Use `git switch -c branch_name` to create a new branch and switch to it.

5. **Manish Nalumachu:** Difference between reset and reboot?  
   **Answer:** `reset` resets a system or its settings depending on the context, while `reboot` restarts the computer.

6. **Masarpu Jyothish:** Use of zip in dictionary?  
   **Answer:** `zip()` combines elements from multiple iterables into tuples. We can use `dict(zip(keys, values))` to create a dictionary from two lists.

7. **Mohd Saad Shaikh:** How can we remove the last element?  
   **Answer:** Use `list.pop()` to remove the last element from a list. It also returns the removed element.

8. **Moyya Naveen:** What is range in Python and why do we use it?  
   **Answer:** `range()` generates a sequence of numbers. We mainly use it in loops to repeat an operation a specific number of times.

9. **Mudrakola Sai Pavan:** What is the man command?  
   **Answer:** The `man` command displays the manual or documentation of another command. Example: `man ls`.

10. **Neha Sunil Magadum:** Is a dictionary ordered or unordered?  
    **Answer:** Dictionaries are ordered in Python. They maintain insertion order.

11. **Palepu Veerababu:** Difference between set and tuple?  
    **Answer:** A set is a collection of unique elements, whereas a tuple is an ordered collection that allows duplicate elements and cannot be changed.

12. **Parameswaran R:** While sorting, which command do we use to remove duplicates?  
    **Answer:** Use `sorted(set(my_list))` to remove duplicates and sort the elements in ascending order.

13. **Pavan Kumar:** How to unstage a file?  
    **Answer:** Use `git restore --staged filename` to unstage a file.

14. **Raghu B S:** Can we use a number at the beginning while declaring variables?  
    **Answer:** No, variable names cannot start with a number. They can start with a letter or underscore. Example: `name1` is valid, but `1name` is invalid.

15. **Shakthivel:** Why do we use the status command?  
    **Answer:** The `git status` command shows the current state of the working directory and staging area, including modified, staged, and untracked files.

16. **Sunkara Prasanth:** What is sudo and why do we use it?  
    **Answer:** `sudo` allows a permitted user to execute commands with administrator privileges. Example: `sudo apt update`.

17. **Varad Rajesh Barbhai:** What is the use of for-else in a loop?  
    **Answer:** The `else` block executes when a loop finishes normally without encountering a `break` statement.
